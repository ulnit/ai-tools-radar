# How I Built a Fully Automated AI Tools Radar on a $35 Raspberry Pi

## The Problem: Too Much AI Noise

Every day, hundreds of new AI tools launch on GitHub. Hacker News threads explode with hot takes. Reddit communities debate the next breakthrough. As a developer, staying informed means hours of doom-scrolling through noisy feeds.

**What if an AI agent could do this for me — 24/7, on a $35 computer?**

## The Solution: AI Tools Radar

I built **AI Tools Radar** — a fully automated intelligence system that:

- 🔥 Scrapes **GitHub Trending** for repos with 100+ stars
- 📰 Monitors **Hacker News** for AI/automation discussions
- 🤖 Tracks **Reddit** r/MachineLearning community picks
- 📝 Curates trending articles from **Dev.to**

Every Monday morning, it delivers a clean, curated report directly to your inbox.

## The Architecture

The entire system runs on a **Raspberry Pi 4** (4GB RAM, ARM64, Debian):

```
Cron Job (Weekly, Monday 9AM)
    ↓
Python Scraper (stdlib only — no pip needed!)
    ↓
4 Data Sources (GitHub API, HN Algolia, Reddit JSON, Dev.to API)
    ↓
HTML Report Generator (included with subscription)
    ↓
GitHub Pages Deployment (auto-pushed)
```

## Why This Matters

1. **Zero ongoing cost** — runs on hardware that costs 2¢/day in electricity
2. **100% automated** — no human curators, no editorial bias
3. **Always fresh** — data is scraped hours before delivery
4. **Actionable** — filtered for signal, not noise
